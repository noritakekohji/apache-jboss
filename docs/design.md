# Apache / JBoss ログ分析ツール 設計メモ

更新日: 2026-11-26
状態: 初期実装

## 目的と前提

Windows端末上でApacheアクセスログ、JBossサーバーログ、Java GCログを読み込み、遅延、HTTPエラー、JBoss例外、Full GCの状況を調べる。利用者は一人、出力は他者と共有する。ログ時刻は日本時間、対象はおおむね1日分、利用規模は約20人。実ログの持ち出しは禁止し、開発時は合成データのみ使う。

## 実装方針

- Windows PowerShell 5.1とWindows Formsを使い、追加ランタイムや外部モジュールを要求しない。
- Apache Combined形式を基本とし、末尾の秒単位レスポンスタイムは任意項目として読む。標準Combinedだけでは処理時間が記録されないことを明示する。
- JBossの日時・ログレベル付きプレーンテキスト形式と、Java GCログの限定された既知形式を読む。未認識行は数と理由を報告する。
- ログIDを確認できない間はApache/JBossのイベントを取引単位で結びつけない。時間的な近さを因果と誤認させない。
- HTMLはクエリ文字列を除き、外部CDNを使わない。CSVもURLクエリを既定で削り、数式インジェクションを防ぐ。

## 初期版の制限

初期GUIと集計は基本機能の実装段階である。Apache Combinedの標準形式には処理時間欄がないことが多く、その場合レスポンスタイム指標は空になる。JBossログの複数行スタックトレースは現在は個別行扱い。GC形式はJavaバージョン・ベンダーで異なるため、実環境との適合をログを持ち出さず利用端末上で確認する必要がある。インタラクティブな時系列比較、期間フィルター、エンコード選択、マスキングプレビュー、イベント行のHTML詳細は今後の改善項目。

## 共有出力

HTMLレポートとリクエスト/JBoss/GC別CSVをデスクトップに出力する。ログ本文はHTMLに含めず、URLクエリ文字列は除外する。出力先を選ぶ機能やプレビューは次段階で追加する。
